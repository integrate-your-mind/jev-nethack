# Frontier v2: protocol before gameplay requests

This records a frozen, exploratory direct-Jev policy comparison before its first gameplay provider request. The earlier cycle-aware-v1 result was negative. No ascension, generalization, or live-policy benefit is claimed here.

The candidate retains an observation-only spatial graph. Jev chooses both a short goal and every actual action from all 121 candidates. The comparison uses two predetermined branch points from the same episode, with 32 future actions per arm. These are development comparisons, not independent held-out episodes. The operational addendum defines the primary new-position metric, safety checks, known semantic limitations, and all stopping rules.

Every attempted request counts toward a durable 192-attempt cap, including failures and ambiguous interruptions. The trial has one execution authorization, no provider retries, no replacement branch points, and no rerun after interruption. Every partial result remains evidence. The isolated trial may run alongside the public game; no wall-clock throughput comparison is claimed.

`public-anchor.json` binds the unmodified private harness, replay proof, and complete freeze receipt by SHA-256. `harness-freeze.public.json` replaces only the two private absolute root paths; the other published contracts match their original bytes. The full harness and all resulting observations and decisions will accompany the result release, including negative or incomplete results.

Independent review and an explicit execution release are still required. This publication alone does not claim the trial has run or authorize a live migration.

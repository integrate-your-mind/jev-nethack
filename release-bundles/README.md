# Completed recording release bundles

These bundles contain the actual completed MP4 and NDJSON artifacts from two closed runs, plus the per-segment manifests needed to verify their hashes. They are immutable release inputs; the local originals remain preserved separately.

- `hour-20260918T050819Z/`: 2,501 actions, 27 completed segments, ended after a Jev transport error
- `smoke-v2/`: 24 actions, 5 completed segments, bounded smoke run

Configuration files, launch logs, host paths, token files, credentials, upload receipts, and active or unfinished recordings are excluded. The old iCloud-only pilot checkpoints and result files were not available during this publication and are explicitly not recreated.

# v0.1.0-recordings

This release publishes the bounded Jev × NetHack runner/research snapshot and two completed recording bundles.

The 2,501-action hour run ended after a Jev transport error. The 24-action smoke run ended at its configured action cap. Neither is a win or state-of-the-art result. The old iCloud-only pilot checkpoints and result files were unavailable during publication and were not regenerated.

The downloadable archives contain only completed MP4/NDJSON recording artifacts and per-segment manifests. `release-assets/ASSET_SHA256SUMS.json` provides SHA-256 hashes for the release archives; `release-bundles/SHA256SUMS.json` covers the files inside each bundle.
